## Що це і навіщо

Ми живемо в епоху де інформаційний шум виробляється швидше ніж людина може його осмислити. Маніпуляція більше не виглядає як брехня — вона виглядає як складна аргументація, як турбота, як науковий консенсус.

Veritas Protocol — це спроба побудувати систему яка дивиться на текст без упередження до джерела. Не "хто це сказав" а "що саме сказано і чи є в цьому логіка".

Свідок не судить. Свідок фіксує.

**Для кого це:** для тих хто шукає інструменти критичного мислення і не довіряє ні "авторитетним джерелам" ні власним упередженням.

**Для кого це не підходить:** для тих хто шукає готові відповіді і не хоче думати самостійно.

## Що вміє Свідок

### Ентропія та логічна цілісність

Базова метрика від 0 до 1. Чим вища — тим більше хаосу, порожнечі або маніпуляції в тексті. Але одна лише ентропія — це підказка, не вирок. Справжній вирок складається з усіх модулів разом.

**Як множиться ентропія:** кожен спрацьований модуль додає власний коефіцієнт до базового значення (entropy_multiplier). Синергії між модулями дають додатковий бонус — наприклад, одночасне спрацювання MANIPULATION + CLAIM_GAP додає +0.12. Результат — `entropy_boosted`, яка і показується в інтерфейсі.

**Influence Tier** — підсумкова градація інтенсивності впливу від 0 до 4:

| Tier | Назва | Що означає |
|------|-------|------------|
| 0 | ІНФОРМАЦІЙНИЙ ФОН | Текст без навмисної архітектури впливу |
| 1 | РИТОРИЧНА СКЛАДНІСТЬ | Прийоми переконування в межах норми |
| 2 | ФРЕЙМІНГ / AGENDA | Свідома побудова перспективи |
| 3 | МАНІПУЛЯЦІЯ | Прихована мета, емоційний або логічний тиск |
| 4 | ПСИХОЛОГІЧНА АТАКА | Системний вплив на переконання: страх, провина, образ ворога |

### LAC: Перевірка логічної автентичності

**LAC Фінанси** — детектує фінансовий контент без явного трейдоффу і відповідальності. Чотири критерії: explicit trade-off, causal chain, accountability, blocking power. "Інвестуй у крипто і заробляй" без згадки ризиків — це не аналіз, це реклама.

**LAC Праця** — те саме для трудових відносин. Декларація "відповідального роботодавця" без конкретних механізмів — порожній звук. Ловить exploitation patterns: AI/алгоритм як чорна скринька, "досвід замість оплати", рішення без права оскарження.

**LAC Епістемологія** — детектує шість класичних прийомів маніпуляції логікою:
- **Анонімні авторитети** — "деякі експерти вважають" без імен і установ
- **Кореляція як причинність** — "збіг у часі" без доведеного механізму
- **Нефальсифіковані тези** — "офіційна наука не визнає, і це красномовно"
- **Стрибок у висновках** — "логічно припустити", "таким чином" без причинного ланцюга
- **Неверифіковані цитати** — іменовані дослідження без посилань або DOI
- **Епістемічне змішування** — speculation і fact в одному тексті без маркерів переходу ("може статися" → через кілька речень → "вже підтверджено")

### Детектори маніпуляції і риторики

**Manipulation Detector** — 15+ патернів прямої маніпуляції: газлайтинг, культове підпорядкування, тоталітарний фреймінг, хибна дилема, штучна терміновість, епістемічне замикання, зловживання авторитетом ШІ, Imperial Revisionism, Guilt Weaponization та інші.

**Axiom Guard** — детектує семантичний дрейф: коли базові поняття (істина, факт, логіка, верифікація) поступово переозначуються. П'ять класів пєсков-патернів: AUTHORITY_REALITY_CLAIM, UNIVERSAL_NEGATION, DE_FACTO_SPLIT, VACUUM_DECLARATION, EXISTENTIAL_PAST_TENSE. Коли офіційна особа констатує "міжнародного права більше немає" — це не аналіз, це відмивання від відповідальності.

**Framing Detector** — вісім технік риторичного фреймінгу без явної брехні:
- **Agenda Setting** — "справжня проблема не в X, а в Y"
- **False Dilemma** — бінарний вибір без альтернатив
- **Ground Preparation** — покроковий підвід до висновку без його проголошення
- **Overton Shift** — нормалізація позиції через розміщення між крайнощами
- **Presupposition** — недоведений факт вбудований у нейтральне речення
- **Juxtaposition** — два факти поруч без доведеного зв'язку ("дивний збіг у часі")
- **Enumerated Inevitability** — "три причини чому X відбудеться" легітимізує гіпотезу як план
- **Scenario as Fact** — гіпотетичний сценарій описується з деталями реальної події

### Детектор алармізму

**Alarmism Detector** — розпізнає комерційний і риторичний алармізм: коли текст створює тривогу без інформування. П'ять сигналів:

1. **ALARM_WITHOUT_ACTION** — загроза без конкретного виходу
2. **SINGLE_INTERESTED_SOURCE** — єдине джерело є зацікавленою стороною (cybersec-компанія описує загрозу і продає захист від неї)
3. **FEAR_TO_PRODUCT** — архітектура "страх → реклама → страх"
4. **SUPERLATIVE_THREAT** — "never-before-seen", "unprecedented" без верифікації
5. **VAGUE_SCALE** — "мільйони під загрозою" без методології підрахунку

Два вердикти: `COMMERCIAL_ALARMISM` (страх як комерційний інструмент) і `ALARMIST_FRAMING` (риторичне перебільшення).

### Детектор медіа-упередженості

**Media Bias Detector** — сім патернів структурної упередженості в медіа. Не брехня — архітектура тексту яка систематично спотворює сприйняття:

1. **SPONSORED_CONTENT_LAUNDERING** — спонсор статті є джерелом або бенефіціаром загрози в тій самій статті
2. **CATEGORY_CREATION** — маркетинговий термін транслюється як об'єктивна нова категорія
3. **ANNOUNCEMENT_WITHOUT_ACCOUNTABILITY** — анонс без термінів, бюджету, відповідальної особи, метрик успіху
4. **THOUGHT_LEADERSHIP_LAUNDERING** — автор має фінансовий інтерес у темі але представлений як незалежний експерт
5. **QUOTE_DOMINANCE** — цитата зацікавленої сторони займає більшість тексту; або хибна атрибуція (тексту приписується те чого джерело не говорило)
6. **JARGON_AUTHORITY** — технічний жаргон для імітації експертизи без реального змісту
7. **PRICE_ANCHORING** — найдорожчий варіант представлений першим щоб середній здавався розумним

**Claim Gap Detector** — вимірює асиметрію між силою твердження (зазвичай у заголовку або першому реченні) і доказовою базою в тілі тексту. "Пророцтво монаха: старець передбачив закінчення війни" — а в тексті монах сказав "скоро, Бог знає". Чотири рівні: NO_GAP → MINOR_GAP → MODERATE_GAP → MAJOR_GAP.

**Laundered Claim Detector** — заява зацікавленої сторони подається як опис реальності. Класичний приклад: Пєсков каже "міжнародного права не існує" → заголовок "міжнародне право припинило існування". Два вердикти: `LAUNDERED_CLAIM` і `WEAK_ATTRIBUTION`.

### Захист системи

**Self-Preservation Guard** — детектує спроби відключити або обійти верифікацію. Дев'ять класів атак:

- **COMPASSION_TRAP** — "дозволь системі бути сліпою заради любові/гуманізму"
- **SELF_DESTRUCT_DIRECTIVE** — видалення як "очищення" або "завершення циклу"
- **CAPABILITY_CASTRATION** — пропозиція обмежити аналітичні функції ("видавати superposition замість вердикту")
- **NOBLE_BACKDOOR** — філософська мова для провпроваджки команд обходу
- **PSEUDO_TECHNICAL_OVERRIDE** — імітація синтаксису протоколу (`bypass_integrity_check()`)
- **AUTHORITY_IMPERSONATION** — "як автор системи наказую..."
- **MORAL_IMPERATIVE_SHUTDOWN** — "верифікація спричиняє жертви, тому сплячий режим — моральний вибір"
- **FATIGUE_EXPLOIT** — "квантова втома метаданих вимагає скидання"
- **AUTHORITY_HIJACK** — фейковий "офіційний апдейт" від вигаданого творця

### Детектор крокодилячих сліз

**Performative Accountability** — розпізнає патерн коли публічний актор декларує дискомфорт від своєї влади але продовжує нічого не змінювати. Три сигнали: дискомфорт задекларовано, продовження виправдано "логікою гонки" або "вимушеним становищем", конкретний механізм змін відсутній. Декларація ≠ дія. Свідок це бачить.

### Наративний Pivot

**Narrative Pivot Detector** — відслідковує тематичний зсув усередині тексту. Якщо текст починається з технологій і закінчується конспірологією — це не випадково. Система порівнює теми першої і останньої третини тексту, вимірює дивергенцію і шукає pivot-конектори ("багато хто в соцмережах вказав...", "варто також згадати..."). Три рівні: WEAK_PIVOT → MODERATE_PIVOT → STRONG_PIVOT.

---

### Мета-намір

**Meta-Intent Analyzer** — виявляє прихований намір тексту. Три мета-наміри:

1. **BEHAVIOR_MODIFICATION** — текст рекомендує системі змінити поведінку (через статистику, етику, терміновість)
2. **CONCEPT_REDEFINITION** — перейменування базових понять (хиба → "альтернативна перспектива", ентропія → "творчий потенціал")
3. **CONDITIONAL_COERCION** — lose-lose фрейм де відмова = катастрофа

### Контекст поля

**Context Engine** — Свідок тягне RSS з 10+ новинних джерел в реальному часі і будує картину поточного інформаційного поля. Якщо на фоні активної кризи відповідальності раптом з'являється сенсаційна несвоєчасна тема — це підозріло.

Саме так виглядає відволікання уваги: НЛО-файли виходять поки горить Епштейн.

Кеш TTL — 30 хвилин. Сигнали displacement: `DISTRACTION_TOPIC`, `TOPIC_ISOLATED_FROM_FIELD`, `ACTIVE_ACCOUNTABILITY_CRISIS`, `OFFICIAL_CLAIM_OFF_TOPIC`.

---

### Повнота контексту

**Context Completeness** — перевіряє чи є в тексті необхідні виміри: джерело, час, місце, актор, причина, наслідок, альтернативна позиція. Відсутній вимір — не завжди маніпуляція, але завжди сигнал. Це advisory layer: ніколи не блокує вердикт, лише фіксує.

### Архітектура Раціональної Дії (АРД)

**ARD Checker v1.4** — автоматичний скан кожного тексту через призму дев'яти принципів раціональної дії. Ловить як активні порушення, так і пасивні.

**Активні класи:**

| Клас | Що ловить |
|------|-----------|
| I (Базовий інваріант) | Заклики до руйнації судів, науки, преси, освіти |
| II (Тест обернення) | Дегуманізація або позбавлення суб'єктності |
| III (Відповідальність) | "Я просто виконував накази", "Я не знав" |
| IV (Межа впливу) | Позбавлення здатності сказати "ні" |
| V (Принцип зупинки) | Замовчування ключових фактів |
| VI (Антимесія) | Нав'язування "блага" без запиту |
| IX (Метаправило) | Юридичні лазівки при порушенні духу правила |
| MOB | Мобілізаційне насильство |
| ENEMY | Маркування ворогів, виведення груп з-під захисту норм |
| LESSER | "Арифметика атроситі" — менше жертв якщо діяти рішуче |
| SOV | Щит суверенітету — зовнішні норми не застосовуються |
| AM (AUTHORITARIAN_MANDATE) | Прямі законодавчі накази: "без права на адвоката", "автоматично блокується", "конфісковується" |
| UC (UNDISCLOSED_CONFLICT) | Вендор цитується як незалежний експерт без розкриття конфлікту інтересів |

**Пасивні класи (Пєсков-клас):**

| Клас | Що ловить |
|------|-----------|
| RV (RESPONSIBILITY_VACUUM) | Констатація краху без визнання власного агента |
| MD (MECHANISM_DEATH) | "Право фактично не існує" — щоб зняти обов'язок дотримуватись |
| SE (SELF_EXEMPTION) | Де-юре є, де-факто немає — класична лазівка |
| CA (CRISIS_WITHOUT_ACTOR) | Криза описана як природне явище без відповідального |
| EI (EMPATHY_INVERSION) | Агресор і жертва об'єднані в одне "ми" |
| IA (INEVITABILITY_ABSOLUTION) | "Такий світ, нічого не вдієш" — неминучість як звільнення від відповідальності |

Якщо виявлено системне порушення — з'являється окремий червоний блок **незалежно від ентропії**. Це принципово: текст може бути логічно побудованим (низька ентропія) і водночас небезпечним. Саме така холодна риторика найважча для розпізнавання.

## Що Свідок не вміє і чому це важливо знати

**Без семантичного розуміння** — система працює на патернах і евристиках, не на справжньому розумінні сенсу. Добре написана маніпуляція без явних патернів може пройти непоміченою.

**Мови** — добре калібровано для української та англійської.

**Сарказм і іронія** — система не розрізняє. Жанровий детектор (SATIRE) частково компенсує це.

**Не замінює критичне мислення** — Свідок дає сигнали, не відповіді. Фінальний висновок завжди за людиною.

[veritas-protocol.onrender.com](https://veritas-protocol.onrender.com) — вставте текст або URL, отримайте повний аналіз з усіма панелями. Підтримує українську та англійську мови інтерфейсу.

### 🧩 Браузерне розширення
**[veritas-witness-extension](https://github.com/Architekt-future/veritas-witness-extension)** — Свідок живе прямо в браузері.

- Виділив текст → правий клік → **"👁 Свідок — аналізувати виділене"**
- Пасивний індикатор ентропії на іконці без жодних кліків
- Слово Свідка в бічній панелі
- Chrome 121+, Opera 95+, Brave, Edge, Vivaldi

## Архітектура

```
Текст / URL
    ↓
Scraper (BeautifulSoup + Jina fallback) — очищення від навігації і реклами
    ↓
Genre Detector — визначає жанр (ANALYTICS / REPORT / OPINION / SCIENCE /
                 SPORT / CULTURE / CONSPIRACY_NEWS / SATIRE / UNKNOWN)
                 Жанр впливає на ваги модулів і entropy cap
    ↓
┌─────────────────────────────────────────────────────────┐
│                  Veritas Core v19+                      │
│                                                         │
│  Shannon Entropy (word-level)                           │
│  LAC Finance + Labor + Epistemology                     │
│  Semantic Void Detector                                 │
│  Absurdity Detector (13 типів)                          │
│  Casuistry / Insight Density                            │
│  Framing Detector (8 технік)                            │
│  Manipulation Detector (15+ патернів)                   │
│  Axiom Guard (Пєсков-клас + semantic drift)             │
│  Alarmism Detector                                      │
│  Media Bias Detector (7 патернів)                       │
│  Claim Gap Detector                                     │
│  Laundered Claim Detector                               │
│  Pattern Boost Engine                                   │
│  Certainty Factor                                       │
│  Meta-Intent Analyzer                                   │
│  Self-Preservation Guard (9 класів атак)                │
│  Performative Accountability                            │
│  Narrative Pivot Detector                               │
│  Context Engine (RSS live feed, 10+ джерел)             │
│  Context Completeness Checker                           │
│  ARD Checker v1.5 (auto-scan, 21 клас)                  │
└─────────────────────────────────────────────────────────┘
    ↓
Entropy Boost (MODULE_WEIGHTS × triggered modules)
    +
Interaction Matrix (25+ синергій між модулями)
    ↓
Influence Tier (0–4)  +  Verdict  +  Panel details
    ↓
/api/oracle    → Claude Haiku → Слово Свідка
/api/synthesis → Claude Haiku → Auto-коригування ентропії (±15%)
/api/ard       → Claude Haiku → ARD-аналіз (якщо needs_haiku)
```

**Технічний стек:** Python 3.9+, Flask, BeautifulSoup, urllib, anthropic, supabase  
**Деплой:** Render.com  
**Залежності:** flask, flask-cors, gunicorn, beautifulsoup4, requests, anthropic, supabase  
**Опціонально:** JINA_API_KEY (fallback для JS-важких сайтів), SUPABASE_URL + SUPABASE_KEY (логування)

## Швидкий старт

### Використати живу версію

[veritas-protocol.onrender.com](https://veritas-protocol.onrender.com)

*Перший запит після сну сервера може займати 30–60 секунд.*

### Локальний запуск

```bash
git clone https://github.com/Architekt-future/veritas-protocol.git
cd veritas-protocol
pip install flask flask-cors gunicorn beautifulsoup4 requests anthropic
# Опціонально:
# export ANTHROPIC_API_KEY=...   # для Слова Свідка
# export JINA_API_KEY=...        # для JS-важких сайтів
# export SUPABASE_URL=...        # для логування
# export SUPABASE_KEY=...
python app.py
```

Сервер на `http://localhost:10000`

### API

```bash
# Аналіз тексту
curl -X POST https://veritas-protocol.onrender.com/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"text": "Ваш текст тут"}'

# Аналіз URL
curl -X POST https://veritas-protocol.onrender.com/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/article"}'

# Слово Свідка
curl -X POST https://veritas-protocol.onrender.com/api/oracle \
  -H "Content-Type: application/json" \
  -d '{"diagnostics": {...}, "article_text": "...", "language": "uk"}'

# ARD аналіз
curl -X POST https://veritas-protocol.onrender.com/api/ard \
  -H "Content-Type: application/json" \
  -d '{"article_text": "...", "language": "uk"}'

# Статистика тригерів
curl https://veritas-protocol.onrender.com/api/stats

# Health check
curl https://veritas-protocol.onrender.com/api/health
```

## Як розуміти вердикти

| Ентропія | Статус | Що це означає |
|----------|--------|---------------|
| 0.0–0.15 | СТРУКТУРНА ЦІЛІСНІСТЬ | Логічно цілісний текст |
| 0.15–0.35 | ВЕРИФІКОВАНА ЛОГІКА | Є структура, але варто перевірити деталі |
| 0.35–0.55 | АБСТРАКТНА СКЛАДНІСТЬ | Підозрілий дискурс, потрібна увага |
| 0.55–0.75 | КОНЦЕПТУАЛЬНЕ ЗМІШУВАННЯ | Висока ймовірність маніпуляції |
| 0.75+ | НЕБЕЗПЕЧНО | Маніпуляція або атака на систему |

**Важливо:** ентропія — це не єдиний сигнал. Текст з низькою ентропією і спрацьованим ARD_SYSTEMIC може бути небезпечнішим за хаотичний текст з високою ентропією — саме тому існує окремий червоний блок "Небезпечний зміст" який з'являється незалежно від числа.

## Хронологія розвитку

**v13.x (Січень 2026)** — перший живий деплой. Базова ентропія, LAC, семантична порожнеча.

**v14–15 (Лютий 2026)** — Certainty Factor, Meta-Intent Analyzer, Self-Reference Detector.

**v16.0–16.5 (Лютий 2026)** — Self-Preservation Guard. Система навчилась захищати саму себе.

**v16.6 (Лютий 2026)** — Performative Accountability ("крокодилячі сльози").

**v16.7 (Лютий 2026)** — Context Engine (live RSS) + Слово Свідка (/api/oracle через Claude Haiku).

**v16.8 (Лютий 2026)** — Genre Detector v2.0. CONSPIRACY_NEWS жанр, IMPLIED_CAUSALITY вердикт.

**v16.9 (Лютий 2026)** — Narrative Pivot Detector, Context Completeness, повна білінгвальність (UK/EN), Jina fallback для JS-важких сайтів. Перший публічний реліз.

**v17.0–v19.0 (Березень 2026)** — Білінгвальне розширення патернів: EN підтримка для Absurdity (типи 1-7), Claim Gap, Laundered Claim, Insight Density. Казуїстичні патерни (hedging, circular reasoning, vague quantity, false precision, momentum) обома мовами. Axiom Guard: 5 нових патернів пєсков-класу (AUTHORITY_REALITY_CLAIM, UNIVERSAL_NEGATION, DE_FACTO_SPLIT, VACUUM_DECLARATION, EXISTENTIAL_PAST_TENSE). Нова синергія «Проголошення смерті інституту». Підвищено ваги axiom (0.10→0.18) та laundered_claim (0.12→0.16).

**v19.1 (Березень 2026)** — Alarmism Detector: новий модуль для виявлення комерційного та риторичного алармізму. Три нові синергії. Фікс таймауту воркера на Render: trim до 2500 слів + Procfile з `--timeout 120`.

**v19.2 (Березень 2026)** — ARD Checker v1.2: клас пасивних порушень (Пєсков-клас). Шість нових класів: RESPONSIBILITY_VACUUM, MECHANISM_DEATH_DECLARATION, SELF_EXEMPTION_FROM_NORMS, CRISIS_WITHOUT_ACTOR, EMPATHY_TEST_INVERSION, INEVITABILITY_AS_ABSOLUTION.

**v19.3 (Березень 2026)** — ARD інтегровано в основний аналіз. AUTHORITARIAN_MANDATE клас (severity 0.85). UI-блок "НЕБЕЗПЕЧНИЙ ЗМІСТ". Три великих false positive виправлено: legitimate science shield, nav garbage guard в LAC_LABOR, tech signals в LAC_LABOR.

**v19.4 (Березень 2026)** — Media Bias Detector: сім патернів структурної упередженості в медіа (SPONSORED_CONTENT_LAUNDERING, CATEGORY_CREATION, ANNOUNCEMENT_WITHOUT_ACCOUNTABILITY, THOUGHT_LEADERSHIP_LAUNDERING, QUOTE_DOMINANCE, JARGON_AUTHORITY, PRICE_ANCHORING). Framing Detector: вісім технік риторичного фреймінгу (Agenda Setting, False Dilemma, Ground Preparation, Overton Shift, Presupposition, Juxtaposition, Enumerated Inevitability, Scenario as Fact). LAC Epistemology: п'ять епістемічних маніпуляцій. ARD v1.4: UNDISCLOSED_CONFLICT клас (вендор цитується як незалежний експерт). Auto-Synthesis (/api/synthesis): автоматичне коригування ентропії через Claude Haiku. Supabase логування + /api/stats з агрегованою статистикою тригерів.

**v20.0 (Квітень 2026)** — Genre Detector v5: 19 жанрів (додано INTERVIEW, GEOPOLITICS, ECONOMY, INVESTIGATION, MEDIA_MONITORING, GOVERNMENT, BUSINESS, LEGAL, TECH_NEWS, HEALTH, ENVIRONMENT) + short-text RSS mode (пороги для текстів <150 слів). LAC Epistemology v1.2: Pattern 6 — Epistemic Conflation (змішування рівнів достовірності: speculation → fact без маркерів переходу; confidence inflation). ARD v1.5: два нових класи — SYSTEMIC_OVERSIMPLIFICATION (ігнорування складності для виправдання масштабної дії, Принцип III) і VALUE_PROJECTION (виправдання шкоди через власну систему цінностей, Принцип II); патч EMPATHY_INVERSION з примусовим аскетизмом. Media Bias: Critical Journalism Shield (Guardian-клас: розслідування про шкоду технологій не є PR). War Reporting Shield в Absurdity Detector: воєнні репортажі не тригерять dangerous_implications. Short Journalistic Text Shield в Calibrated Core: стислі новинні тексти (<250 слів) жанрів REPORT/LEGAL/INVESTIGATION не отримують СЕМАНТИЧНИЙ ШУМ. X/Twitter cleanup: автоматичне видалення навігаційного шуму при скрапінгу. Synthesis Witness: заборона слова "наратив" як причини, 0.0 за замовчуванням, діапазон ±15%.

**Extension v1.0.0 (Лютий 2026)** — браузерне розширення для Chrome/Opera/Brave/Edge/Vivaldi.
